
# Ejercicio 051: Conteo Combinatorio Simple (Kickboxing)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de kickboxing, aplicando lógica de conteo combinatorio para evaluar pares o combinaciones posibles entre los datos de entrada, combinándolo con promedios, bonificaciones y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de datos de entrada contenga elementos.
2. **Conteo Combinatorio:** Se calcula el número de combinaciones posibles de los elementos del arreglo tomando pares de combatientes (`n * (n - 1) / 2`).
3. **Cálculo Numérico:** Se integra el promedio de los participantes con el factor combinatorio, sumando el bono y restando la penalización.
4. **Condicionales:** Se clasifica el nivel según la categoría deportiva ("categoria profesional", "categoria amateur", "categoria novato").
