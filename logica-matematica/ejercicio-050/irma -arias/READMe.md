
# Ejercicio 050: Redondeo y Precisión (Viajes y Turismo)

## 🚀 Descripción del Problema
Este reto consiste en procesar arreglos numéricos bajo la temática de viajes y turismo, aplicando ciclos acumuladores, manejo estricto de la precisión decimal en cálculos de promedios y redondeo numérico para ajustar el puntaje final con bonos y penalizaciones.

## 🛠️ Reglas Aplicadas
1. **Validación:** Se verifica que la lista de datos de entrada contenga elementos.
2. **Ciclo y Precisión:** Se recorre el arreglo calculando la suma y obteniendo un promedio con control de decimales precisos (`toFixed`).
3. **Cálculo Numérico:** Se computa el resultado aplicando operaciones aritméticas y redondeo estricto.
4. **Condicionales:** Se clasifica el tipo de experiencia turística ("turismo de lujo", "viaje estandar", "excursion economica").
