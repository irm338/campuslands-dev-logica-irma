
# Ejercicio 057 - Tablas de Decisión (Arquitectura 3D)

## 1. ¿Cómo pensé el problema?
Desglose el problema analizando que una tabla de decisión permite estructurar múltiples condiciones concurrentes (complejidad, viabilidad financiera y normativas técnicas) para tomar una decisión automatizada sobre si un proyecto de arquitectura 3D puede proceder o debe ser rechazado.

## 2. Reglas aplicadas
* **Validación inicial:** Comprobar que el arreglo recibido contenga elementos y no esté vacío.
* **Evaluación de complejidad y presupuesto:** Exigir aprobación financiera estricta para obras de alta complejidad.
* **Control técnico obligatorio:** Dictaminar el rechazo automático de cualquier proyecto que carezca del estudio de suelos indispensable.
