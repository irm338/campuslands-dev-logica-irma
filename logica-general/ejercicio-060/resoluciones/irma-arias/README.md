
# Ejercicio 060 - Estrategias de Selección (Comida Urbana)

## 1. ¿Cómo pensé el problema?
Desglose el problema analizando que una estrategia de selección comercial requiere establecer criterios de filtrado muy claros (tiempos de entrega óptimos, calificaciones de satisfacción y estándares de frescura) para asegurar que solo los mejores productos de un menú de comida urbana formen parte de la oferta final.

## 2. Reglas aplicadas
* **Validación inicial:** Comprobar que el arreglo recibido contenga elementos y no esté vacío.
* **Control de velocidad operativa:** Descartar opciones que superen los 20 minutos de preparación.
* **Filtro de calidad y frescura:** Exigir una calificación mínima de 4.0 estrellas y obligar el uso de insumos frescos del día.
